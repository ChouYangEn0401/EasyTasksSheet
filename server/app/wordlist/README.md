# eff_large_wordlist.txt

產生整站搬家包的解鎖密語（diceware）用的英文單字表。

- 來源：EFF Large Wordlist（7776 字），作者 Electronic Frontier Foundation，
  授權 [CC BY 3.0 US](https://creativecommons.org/licenses/by/3.0/us/)。
  原始出處 <https://www.eff.org/dice>；本檔取自 PyPI 套件 xkcdpass 1.30.0 內附的 `eff-long`（內容相同）。
- 修改：移除 4 個含連字號的字（避免和密語的分隔符號 `-` 混淆），剩 7772 字。
  每個字約 12.9 位元，8 個字約 103 位元。
