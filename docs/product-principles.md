# 產品原則

## 總覽：看見彼此，而不是評比彼此

我們希望團隊能大致看見每個人最近在忙些什麼，必要時能主動伸出手、或重新安排工作。總覽（含「近三週」）是為了**互相支援與安排**，**不是**績效評比或監控工具。

因此在呈現上，我們盡量做到：

- **不排名、不比較**：不列「最多 / 最少 / 落後」，也不做個人之間的百分比或精確工時對比。直條高度以全隊共同的尺度呈現，只是幫助大略感受份量。
- **語氣中性**：數字用中性、柔和的顏色，搭配「大約」的語氣；不使用紅色或橘色警示來標示某個人的工作量。
- **尊重沒有紀錄的時候**：某週沒有資料時寫「這週沒有紀錄」，而不是「沒做事」。休假、開會、支援他人、處理系統外的工作都很常見，紀錄本來就不會完整。
- **估時是選填的**：沒有填預估工時，就只呈現任務件數；有填的才補充「預估工時約 N 小時（M 件有填估時）」，不要求大家為了總覽去填。
- **數字是線索，不是結論**：看到某人最近紀錄較少時，先關心、先問「需要幫忙嗎」，而不是下判斷。

新增或調整總覽相關功能時，請先對照以上原則。
