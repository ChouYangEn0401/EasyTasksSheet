# 設計規格 — T1 feat/task-list

適用分支：`feat/task-list`，檔案範圍 `src/web/features/tasks/**`。token 與基礎元件一律引用 `core-shell.md`（下稱 core），本文件**不新增 token、不改 `ui/`、`shell/`**。core 沒有的浮層（Popover）在本資料夾內自建，外觀沿用 core Select 面板樣式（surface、border、`--radius-lg`、`--shadow-md`、`--z-popover`）。

## 1. 範圍與原則

- 四塊：List 檢視（`/tasks/list`）、QuickAdd 升級、TaskDrawer 升級為可編輯、自訂 property 介面。
- **無儲存按鈕**：每個欄位提交即寫入（PATCH 只送該欄位），樂觀更新；失敗回復原值並在該儲存格顯示錯誤。Toast 由 T9 補，T1 不依賴。
- 就地編輯器（§4）是**同一組元件**，List 儲存格與 Drawer 欄位列共用，只差外框尺寸。
- 中文輸入法組字中（`isComposing`）的 Enter / Esc 一律不觸發提交或取消。
- 30 秒輪詢與 focus 重抓時，**編輯中的儲存格不被覆寫**，其餘靜默更新。

## 3. List 元件與狀態

### 3.1 工具列（ViewTabs actions）
- **分組** Select（secondary `sm`）：`狀態`（預設）／`負責人`／`專案`／`不分組`。寫入 URL `group=`。
- **欄位** Popover（寬 260）：列出全部欄位，每列 Checkbox + 型別圖示 + 名稱；標題欄固定勾選且停用。底部分隔線下「+ 新增欄位」。顯示 / 隱藏存 `localStorage`（鍵 `tasks.list.columns`，僅本機）；不做欄位拖曳排序，順序依 `property_defs.sort_order`。

### 3.2 表頭
- 高 36、`--color-bg` 底、`--text-xs` 500 text-secondary。hover：surface-hover，尾端出現 chevron。
- 點欄名循環排序：升冪 ↑ → 降冪 ↓ → 取消（回到 `sort_order`）；排序中的欄名轉 `--color-text` 並顯示箭頭，`aria-sort` 同步。寫入 URL `sort=<欄位鍵>&dir=asc|desc`（自訂欄鍵為 `p<id>`）。空值恆排最後；排序在群組內進行。
- 點 chevron / 右鍵開**欄位選單**（Menu）：升冪排序、降冪排序｜重新命名、編輯選項（僅 select 類）｜隱藏欄位｜刪除欄位（danger-text）。內建欄位只有排序與隱藏；標題欄不可隱藏。
- 最右「+」ghost iconOnly（`aria-label="新增欄位"`）開啟 §6.1 面板。

### 3.3 群組列
- 高 36、`--color-bg` 底、內距 0 12px：chevron 16 + 群組標示（狀態用唯讀 StatusBadge、負責人用 Avatar `xs` + 名稱、專案用色點 + 名稱）+ 計數 Badge（neutral、計數型）。
- 整列可點收合 / 展開（`aria-expanded`），收合狀態存 `localStorage`。hover：surface-hover。
- 依狀態分組時**空群組仍顯示**（計數 0，只有插入列）；其他分組只顯示有任務的群組，「未指派」排最後。

### 3.4 任務列
| 狀態 | 外觀 |
|---|---|
| 預設 | surface 底、下緣 `--color-border-subtle` |
| hover | surface-hover；標題尾端出現「開啟」ghost `sm` 鈕與 `PinButton` 插槽 |
| 選取（Drawer 正開著此任務） | accent-soft 底、左緣 2px accent |
| 已完成（category=done） | 標題 text-tertiary + 刪除線，其餘欄不變 |
| 剛建立 / 剛因編輯而移動 | accent-soft 底 1.2 秒後恢復（T9 再換成動畫） |
| 寫入中 | 不變色；超過 400ms 才在該儲存格尾端顯示 16px Spinner |

- **完成鈕**（勾選欄，18px 圓圈）：一次點擊改為第一個 `done` 類狀態，圓圈變 success 底白勾；再點一次回到第一個 `todo` 類狀態。`aria-label="標記為完成"`、`aria-pressed`。
- **狀態格**：`interactive` StatusBadge，點一下直接開面板，選一項即提交並關閉（不需先進入編輯模式）。
- **標題格**：點文字進入編輯；「開啟」鈕或 `Space` 開 Drawer（`openTask(id)`）。溢出以省略號截斷，tooltip 顯示全文。
- **到期日**：早於今天且未完成 → `--color-status-overdue-text`。**更新欄**：`<UpdatedAt at by>`，唯讀。
- 編輯使列換到別的群組 / 排序位置時，列立即移動，鍵盤 focus 跟著該列。

### 3.5 頁面級狀態
| 情況 | 畫面 |
|---|---|
| 載入中（首次） | 表頭 + 8 列 Skeleton（每格一條，標題格寬 60%） |
| 錯誤 | 表格區改為 ErrorState「載入失敗」+ 重試 |
| 完全沒有任務 | EmptyState「還沒有任務」，說明「按 `N` 或在下方輸入標題開始新增」，下方保留一條插入列 |
| 篩選後無結果 | 沿用 core：EmptyState「沒有符合條件的任務」+ 清除篩選 |
| 寫入失敗 | 該格錯誤態（§4.2）；表格上方 danger-soft 提示列「未能儲存變更：<訊息>」，可關閉，下次成功寫入時自動消失 |

## 4. 就地編輯器（List 儲存格與 Drawer 共用）

### 4.1 各型別
| 欄位 / 型別 | 顯示 | 編輯器 | 提交 / 取消 |
|---|---|---|---|
| 標題、`text` | 單行截斷 | Input 填滿儲存格（無外框，改儲存格內框） | Enter / 失焦提交；Esc 取消。標題空白 → 不提交並回復 |
| 預估工時、`number` | 右對齊數字；空值「—」 | Input `inputmode="decimal"`；工時限 ≥ 0、0.5 級距 | 同上；非數字 → 錯誤「請輸入數字」 |
| 狀態、`select` | StatusBadge／tag 色 Badge | Select 面板單選，底部「清除」（狀態無此項） | 選取即提交 |
| `multi_select` | 多個 Badge，超出寬度顯示 `+N` | 多選面板（Checkbox），可輸入篩選 | 每次勾選即提交；Esc / 點外部關閉 |
| 負責人、`person` | Avatar `xs` + 名稱；未指派為虛線頭像 +「未指派」text-tertiary | Select 面板（Avatar 選項，首項「未指派」，超過 8 人有搜尋） | 選取即提交 |
| 開始日、到期日、`date` | `MM/DD`，跨年 `YYYY/MM/DD` | Popover 內原生 `<input type="date">`（外觀同 Input）+「清除」ghost 鈕 | 選日期即提交；到期日早於開始日 → 錯誤「到期日不可早於開始日」，不寫入 |
| `checkbox` | 置中 Checkbox | 無編輯模式 | 一次點擊 / Space 切換 |
| `url` | accent-text 連結（截斷），點擊開新分頁；hover 尾端出現鉛筆鈕 | Input；空白處點擊或鉛筆進入編輯 | Enter / 失焦提交；格式不符 → 錯誤「請輸入有效網址」 |
| 專案、優先度（僅 Drawer） | 色點 + 名稱／Badge | Select 面板單選（優先度選項取自 `src/shared` 列舉） | 選取即提交 |
| 進度（僅 Drawer） | 進度條 + `40%` | 原生 range（0–100，級距 5）+ 數字 | 放開即提交 |

### 4.2 儲存格狀態
| 狀態 | 外觀 |
|---|---|
| 預設 | 內距 0 10px；空值顯示「—」`--color-text-tertiary` |
| hover | `--color-surface-active` 底、cursor 依型別（text / pointer） |
| 鍵盤 focus | 內框 2px `--color-accent`（inset，不改變尺寸） |
| 編輯中 | surface 底、內框 accent + `--color-focus-ring` 外光暈；面板型編輯器錨定在儲存格下緣左對齊 |
| 錯誤 | 內框 `--color-danger`；儲存格下方浮出 `--text-xs` danger-text 訊息（`role="alert"`），值回復；再次編輯或 4 秒後消失 |
| 不適用（專案限定欄位遇到其他專案的任務） | `--color-bg` 底、空白、不可聚焦，tooltip「此欄位不適用於該專案」 |

## 5. QuickAdd 升級

沿用 core §7.1 外觀與行為，新增：
- **兩個落點**：Header（全域，`N` 聚焦）與 List 每個群組底部的插入列（`fullWidth`、無邊框、列高 40、前置「+」）。插入列帶入 `defaults`：依狀態分組 → `status_id`；依負責人 → `assignee_id`；依專案 → `project_id`。
- 專案預設：FilterBar 恰好選一個專案時帶入該專案，否則交由後端預設。
- **樂觀插入**：Enter 後立即在對應群組末端出現新列（標題 text-secondary + 尾端 Spinner），成功後轉為正常列並套「剛建立」高亮；輸入框清空並保持 focus。失敗則移除該列、還原輸入內容並顯示 core 的失敗態。
- 新任務不符合目前篩選（因而不會出現在清單）時，輸入框下方提示改為「已建立，但不在目前篩選範圍 · [開啟]」，點擊開 Drawer；5 秒後消失。
- 貼上含換行的文字時換行轉為空白；標題上限依 shared schema，超過時顯示錯誤、不送出。輪詢結果不得搶走 focus 或清掉輸入中的文字。

## 6. 自訂 property 介面

### 6.1 新增欄位面板（Popover 寬 300，由表頭「+」或欄位面板開啟）
```
 新增欄位
 名稱   [______________________]
 型別   [T 文字               ▾]   ← 文字 / 數字 / 單選 / 多選 / 日期 / 核取方塊 / 網址 / 成員
 選項   ● [選項一        ] ✕       ← 僅單選 / 多選顯示
        ● [選項二        ] ✕
        + 新增選項
 範圍   (•) 所有專案  ( ) 僅「預設專案」
                         [取消] [建立]
```
- 開啟即 focus 名稱欄。型別選項各帶 16px 圖示。**型別建立後不可更改**（重新命名與編輯選項可以）。
- 選項列：色點（點擊開 8 色 tag 調色盤，新選項依序輪替顏色）+ Input + 刪除鈕；選項列內 Enter 新增下一列；至少需一個非空選項。
- 範圍：FilterBar 恰好選一個專案時才可選「僅此專案」，否則該項停用並附說明「先篩選單一專案」。
- 「建立」停用條件：名稱空白、名稱與現有欄位重複（名稱欄下方錯誤「已有同名欄位」）、選項不合法。送出中按鈕 loading；API 錯誤顯示在面板頂部 danger-soft 提示列。成功後面板關閉、新欄出現在最右並自動顯示，表格水平捲到該欄。

### 6.2 重新命名 / 編輯選項 / 刪除
- **重新命名**：欄名就地變成 Input（全選），Enter / 失焦提交，Esc 取消；空白或重複則回復並顯示錯誤。
- **編輯選項**：同 §6.1 的選項編輯區（Popover）。刪除仍被任務使用的選項時，該列下方警示「N 筆任務使用中，刪除後這些值會被清除」，按「儲存」才生效。
- **刪除欄位**：Dialog `sm`，標題「刪除欄位「實驗批次」？」，內文「所有任務在此欄位的值將不再顯示，此動作無法復原。」，動作「取消」/ danger「刪除欄位」。預設 focus 在「取消」。

## 8. 互動流程

1. **連續新增**：按 `N` → Header QuickAdd 聚焦 → 輸入標題 Enter → 新列出現並高亮 → 繼續輸入下一筆 → Esc 離開。
2. **就地編輯**：點儲存格（或方向鍵移到後 Enter）→ 編輯 → Enter / 選取 → 值立即更新、列的「更新」欄變為「剛剛」→ 失敗則回復並顯示錯誤。
3. **改狀態**：點 StatusBadge → 面板 → 點選項（或直接點完成鈕一鍵完成）→ 依狀態分組時列移到新群組並高亮。
4. **新增自訂欄位**：表頭「+」→ 填名稱、選型別（單選類再填選項）→ 建立 → 新欄出現 → 直接在儲存格填值。
5. **看 / 改詳情**：列 hover 點「開啟」→ Drawer 滑入、該列呈選取態 → 編輯任一欄位 → 點另一列的「開啟」直接切換內容 → Esc 關閉，focus 回到原列。

## 9. 鍵盤操作（在 core §8 之上追加）

表格為 `role="grid"`，整個表格只佔一個 Tab 停駐點（roving tabindex），群組列與插入列也是 grid 的列。

| 按鍵 | 情境 | 作用 |
|---|---|---|
| `↑` `↓` `←` `→`、`Home` / `End` | 儲存格 focus | 移動（跨群組連續，略過已收合群組的內容）；列首 / 列尾，加 `Ctrl` 為表格第一格 / 最後一格 |
| `Enter` / `F2` | 儲存格 focus | 進入編輯（面板型即開面板；checkbox 與完成鈕為切換） |
| 直接輸入文字 | 文字 / 數字格 focus | 以輸入內容取代原值並進入編輯 |
| `Space` | 儲存格 focus | 開啟該列的 Drawer（checkbox 格與完成鈕為切換） |
| `Delete` / `Backspace` | 非標題格 focus | 清空該值（狀態格無作用） |
| `Enter`、`Tab` / `Shift+Tab` | 編輯中 | 提交並回到儲存格 focus；Tab 為提交後移到右 / 左一格 |
| `Esc` | 編輯中 | 取消、值回復、回到儲存格 focus（優先於關閉 Drawer） |
| `←` / `→` 或 `Enter` | 群組列 focus | 收合 / 展開 |
| `Enter` | 插入列 focus | 聚焦該列輸入框；輸入框內 `Esc` 回到列 focus |
| `Enter` / `Space`、`Alt+↓` | 表頭 focus | 切換排序、開欄位選單 |
| `Ctrl+Enter` | Drawer 描述 | 儲存描述 |

- Drawer 開啟時 focus 移到標題列的關閉鈕；Drawer 內以 Tab 依序走過各欄位，Enter 進入編輯。Drawer 非 modal（≥1024px）時 `F6` 在清單與 Drawer 間切換 focus。
- 螢幕閱讀器：儲存格 `aria-label` 為「<欄名>：<值>」；寫入結果以 `aria-live="polite"` 播報「已儲存」／「儲存失敗」。

## 10. 響應式

| 寬度 | 版面 |
|---|---|
| ≥ 1280px | 如線框。Drawer 開啟時浮在內容右側，表格區塊加 `padding-right: var(--drawer-width)`，確保最右欄仍可捲到可見處 |
| 1024–1279px | 標題欄最小寬縮為 240；其餘欄寬不變，靠區塊內水平捲動；工具列按鈕維持文字 |
| 768–1023px | 標題欄最小寬 200；工具列「分組」「欄位」改 iconOnly + tooltip；列高維持 40，但 hover 才出現的「開啟」鈕、表頭 chevron、url 鉛筆**改為常駐顯示**（觸控無 hover）；Popover 寬度上限 `calc(100vw - 32px)`；Drawer 依 core 轉為 modal（有遮罩），故不加 padding-right |
| < 768px | 不支援，僅需不產生頁面水平捲軸（表格仍在區塊內捲動） |

## 11. 實作備註（T1 實作時補充）

- 欄位顯示 / 隱藏：`localStorage` 鍵 `tasks.list.columns` 存「隱藏」的欄位鍵（新欄位預設顯示）；群組收合存 `tasks.list.collapsed`。
- 依狀態分組且 FilterBar 已篩選狀態時，只顯示被篩選的狀態群組（避免出現一定為空的群組）。
- 「分組」使用 core `Select`（core 無 `sm` 尺寸，故為 `md` 32px）；型別圖示以單一字元表示（core `Icon` 無對應圖示，不改 `ui/`）。
- 自建 Popover 以 portal + `position: fixed` 錨定，避免被表格水平捲動區塊裁切；本資料夾 CSS 為 `features/tasks/tasks.css`，檔首宣告與 Tailwind 相同的 layer 順序。
- 鍵盤：表頭 `Enter` / `Space` 切換排序、`Alt+↓` / 右鍵 / chevron 開欄位選單；`F6` 在清單與 Drawer 間切換。
