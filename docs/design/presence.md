# 設計規格 — feat/presence（在線感知）

適用：`src/web/features/presence/**`、`src/web/lib/presence.ts`，以及 TaskDrawer、清單列、看板卡片上的小接點。色彩、字級、圓角、陰影、動態 token 一律沿用 `core-shell.md` 與 `realtime-feedback.md`，不新增色碼。

原則：像「雲端文件右上角的頭像」一樣輕巧——讓人知道「誰也在、在看哪裡」，方便協作、避免同時改同一欄位；**不是監控**：不顯示精確時間、不排名、不統計時長，並讓每個人能隱藏自己的動態。

## 1. 狀態與資料

| 狀態 | 條件（預設，可由環境變數調整） | 圓點 |
|---|---|---|
| 在線 online | 45 秒內有回報（`PRESENCE_ONLINE_SECONDS`） | 綠 `--color-success` |
| 閒置 idle | 5 分鐘內有回報，或分頁被切到背景（`PRESENCE_IDLE_SECONDS`） | 黃 `--color-warning` |
| 離線 offline | 超過 5 分鐘、或關閉分頁 | 不顯示圓點 |

每位成員：`view`（頁面名稱：總覽、清單、看板、甘特圖、問題回饋、個人清單、工程追蹤…）、`entity`（任務 id、標題摘要、`viewing` / `editing`）、`lastSeenAt`、`lastView`。

## 2. 頂欄「雲端」頭像堆疊

位置：Header 右側、使用者選單左邊。

```
 … [ QuickAdd ]  ( 晴• 一• 阿•  ☁² )  (管) 管理員 ⌄
```

- 圓角膠囊（`--radius-full`），底色 `--color-bg`、1px `--color-border-subtle`。
- 只顯示**其他**在線 / 閒置成員（在線在前、閒置在後），頭像 `md` 28px、彼此重疊 6px、外框 2px surface；最多 5 個，其餘以「+N」。前面的頭像疊在上層，狀態圓點不被遮住。
- 狀態圓點 9px，位於頭像右下，外圈 2px surface。
- 最右邊的雲朵按鈕：有人在線時為 accent 色並帶綠色小數字（在線人數）；只有自己時為 tertiary 灰。
- hover 頭像：上浮 2px（`--duration-fast`）。
- &lt;768px：只留雲朵按鈕（頭像收起），面板仍可展開。

### hover / focus 卡片

延遲 120ms 出現、離開 160ms 後收起（指標可移進卡片）；鍵盤 focus 立即出現，Esc 收起。卡片寬 248px、圓角 14px、`--shadow-md`、1px `--color-border-subtle`，掛在 body 上（不受頂欄 stacking context 限制）。

```
 ┌──────────────────────────────┐
 │ (晴•) 晴恩                   │
 │       在線 · 剛剛            │  ← online 綠字 / idle 黃字
 │ • 正在編輯「ntu ranking new  │  ← 任務名稱可點，開啟該任務
 │   workflow」                 │
 │ 在「清單」頁面               │  ← xs tertiary
 └──────────────────────────────┘
```

文案（`describeMember`，簡潔、親切；引號一律「」）：

| 狀況 | 主句 | 次要 |
|---|---|---|
| 在線、看頁面 | 正在看「甘特圖」 | 在線 · 剛剛 |
| 在線、看任務 | 正在專心看「{標題}」 | 在「清單」頁面 |
| 在線、編輯任務 | （綠色呼吸小點）正在編輯「{標題}」 | 在「清單」頁面 |
| 在線、隱藏動態 | 在線上 | — |
| 閒置 | 剛剛還在看「{頁面或標題}」 | 閒置 · 3 分鐘前；看任務時另附「最後打開：{頁面}」 |
| 閒置、隱藏動態 | 暫時離開一下 | — |
| 離線 | 最後上線 3 小時前 | 最後看的是 清單 |
| 從未上線 | 還沒有上線紀錄 | — |

時間只用相對時間（剛剛 / N 分鐘前 / N 小時前 / 昨天…，同 `formatRelative`），每 30 秒更新。

### 全部成員面板

點任一頭像、「+N」或雲朵展開；點外面或 Esc 關閉（focus 回雲朵）。寬 300px、圓角 14px、最高 480px 可捲動。

```
 大家在哪裡                 一起在線上 ☁
 在線上 2
  (一•) 一般成員
        正在專心看「PR… ntu ranking」
  (晴•) 晴恩
        • 正在編輯「PR… ntu ranking」
 暫時離開 1
  (阿•) 阿德
        剛剛還在看「總覽」 · 4 分鐘前
 離線 2
  (新)  新成員
        最後上線 3 小時前
        最後看的是 清單
 ──────────────────────────────
 ☐ 隱藏我的動態
   開啟後，大家只會看到你在線上
```

- 分組：在線上 → 暫時離開 → 離線；**組內依名稱排序，不依活躍程度排名**。
- 任務名稱可點擊開啟該任務（並關閉面板）。
- 底部「隱藏我的動態」存 `localStorage`（`presence.hideActivity`），開啟後提示改為「大家只會看到你在線上，不會看到你在看什麼」。伺服器端同時尊重：`hidden=true` 時 view / entity 一律置空，「最後看的是」也不記錄。

## 3. 任務層級提示

- **TaskDrawer 提示條**：標題列下方，圓角膠囊；他人在看為 success-soft 底「(晴) 晴恩 也正在看這個任務」，有人編輯為 warning-soft 底「晴恩 正在編輯」；多人「晴恩 正在編輯 · 小明 也在看」、「晴恩 等 3 人 也正在看這個任務」。`role="status"`。
- **清單列**：標題儲存格文字後方 18px 小頭像（最多 2 個 + 數字）；**看板卡片**：像小貼紙一樣探出卡片右上緣（不壓到標題）。
- 編輯中的小頭像有綠色微脈動外圈（1.8 秒循環）；滑鼠停留顯示同提示條文案。
- 「正在編輯」來源：清單 / 抽屜就地編輯欄位（`EditableField` 進入編輯）與描述輸入框 focus；結束編輯或失焦即回到「看」。

## 4. 動畫與 reduced-motion

| 對象 | 進場 | 
|---|---|
| hover 卡片、面板、抽屜提示條 | `translateY(-4px) scale(.96)` → 原位 + 淡入，`--duration-base` `--ease-enter`（輕微彈出） |
| 頭像 hover | 上浮 2px，`--duration-fast` |
| 編輯中小頭像 | 綠色外圈 0 → 3px 呼吸，1.8 秒循環 |
| 卡片中的「正在編輯」小點 | 透明度呼吸，1.8 秒循環 |

`prefers-reduced-motion: reduce`：上述動畫全部取消（直接出現），編輯中的小頭像改為**靜態** 2px 綠框；資訊不因關閉動畫而遺失。

## 5. 回報策略（前端）

- 立即回報（合併 150ms）：路由變更、開啟 / 關閉任務抽屜、編輯開始 / 結束、切換「隱藏我的動態」。
- keepalive：使用者有操作（點擊、鍵盤、滾輪、捲動、滑鼠移動）時每 20 秒最多一次（不超過伺服器在線門檻的一半）；**沒有操作就不送**，讓伺服器自然轉為閒置 / 離線。久未回報後的第一個操作立即送出。
- 分頁隱藏：送一次 `state=idle` 並停止；回來時立即送 `active`。
- 關閉分頁：`pagehide` 時以 `fetch(keepalive)` 送 `state=away`（失敗則由伺服器逾時轉離線）。
- SSE 正常時靠 `presence` 事件更新；SSE 中斷時每 15 秒 GET `/api/presence`。
- PUT `/api/presence` **不刷新閒置計時**（伺服器端例外 + 前端不計為寫入），所以 presence 不會讓人永遠不被登出。

## 6. 無障礙

- 頭像按鈕的名稱即完整描述，例如「晴恩，在線，正在編輯「…」」；雲朵按鈕「全部成員（2 人在線上）」，`aria-expanded`。
- 面板 `role="dialog"`、`aria-label="全部成員"`，開啟時 focus 進入面板；分組為 `section` + 標題。
- 清單 / 卡片小頭像 `role="img"`，`aria-label` 同提示條文案。
