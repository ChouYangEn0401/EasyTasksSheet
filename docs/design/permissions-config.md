# 權限設定頁（/admin/permissions）

讓超級管理員自己決定每個角色能做什麼。規則與 API 見 `docs/permissions.md`〈自訂權限〉。

## 入口與權限

- 側邊導覽「管理」區：成員管理、資料管理之後新增「權限設定」（圖示 `key`），需 `permissions.configure`（僅 root，受保護）。
- 無權限直接開網址：顯示「沒有權限／此頁面僅限超級管理員使用」與「回到總覽」。

## 版面

```
ⓘ 權限設定即時生效；超級管理員永遠擁有全部權限。          [↻ 還原為預設]

┌ 任務與專案 ──────────────────────────────────────────────┐
│ 權限                         超級管理員   管理者    成員   │
│ 編輯任務                        ☑(灰)       ☑        ☑    │
│ 新增、編輯、刪除任務…                                      │
│ 管理專案                        ☑(灰)       ☑        ☐    │
└──────────────────────────────────────────────────────────┘
┌ 狀態 / 工程追蹤 / 成員 / 資料 / 系統 … ───────────────────┐
│ 完整備份下載 🔒                  ☑(灰)      ☐(鎖)    ☐(鎖) │
└──────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────┐  ← 有變更才出現，固定在內容區底部
│ 2 項未儲存變更                         [還原未儲存] [儲存] │
│ 成員：＋管理狀態、－編輯任務                               │
└──────────────────────────────────────────────────────────┘
```

- **分組**：依後端 `CAPABILITY_GROUPS` 順序（任務與專案、狀態、工程追蹤、成員、資料、系統、其他），每組一張卡片（`adm-card`），表格標題為 `<caption>`。未在 `CAPABILITY_INFO` 中描述的新 capability 以代碼為名稱、歸入「其他」，不需改前端。
- **每列**：中文名稱（`font-medium`）＋一句說明（`text-xs`、tertiary）。與預設不同（含未儲存）時名稱旁顯示 `Badge accent`「已自訂」。
- **欄位**：超級管理員（固定打勾、停用，灰底勾選框）、管理者、成員。欄寬 112px（≤1023px 時 84px），置中。
- **受保護項目**：名稱旁小鎖頭（可 Tab 聚焦，Tooltip「僅限超級管理員，無法授予其他角色」）；管理者 / 成員勾選框停用且未勾。
- **未儲存的格子**：底色 `--color-accent-soft`。
- **固定列**（`role="region"`、`aria-label="未儲存的權限變更"`）：sticky 於底部，`shadow-lg`；左側「N 項未儲存變更」＋摘要（成員在前、管理者在後；＋授予、－收回），右側「還原未儲存」（secondary）「儲存」（primary）。窄版摘要換行、按鈕靠右換到下一行。
- 切回原值的格子自動移除變更；全部移除時固定列消失。

## 互動

- **儲存**：一次送出所有變更（`PUT`，單一 transaction）→ 成功 toast「已儲存權限設定」，清空未儲存變更；失敗以頁面 Alert 顯示後端訊息（例如受保護項目的說明），變更保留。
- **還原為預設**：沒有任何自訂時停用；按下開確認對話框（alertdialog）「還原為預設權限？」說明會移除所有自訂並立即生效（有未儲存變更時另提示一併捨棄）→「還原」（danger）→ toast「已還原為預設權限」。
- 儲存 / 還原進行中，勾選框暫時停用。
- **即時性**：寫入後後端記 `permission` 變更流水，所有在線使用者經 SSE 重抓 `/api/auth/me`；其他 root 開著此頁時矩陣也會重抓（未儲存變更保留，與新值相同者自動消失）。

## 狀態

- 載入中：卡片內 6 列 Skeleton。
- 載入失敗：`ErrorState`＋重試。
- 403（例如被降級）：沒有權限畫面。

## 無障礙與鍵盤

- 全部為原生 checkbox，Tab / Space 操作；`aria-label` 為「角色：權限名稱」（如「成員：管理狀態」），超級管理員欄為「超級管理員：X（固定擁有）」。
- 每組表格有 `<caption>`，列首為 `<th scope="row">`。
- 鎖頭可聚焦以讀到 Tooltip；停用的勾選框另有 `title`。

## 響應式

- ≥1024px：最大寬 960px（`adm-page`）。
- 768–1023px：角色欄縮為 84px，說明自動換行；固定列摘要換行。
