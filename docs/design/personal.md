# 設計規格 — feat/personal（T5，輕量）

適用路由 `/me` 與插槽元件 `features/personal/PinButton.tsx`。token 與基礎元件一律引用 `core-shell.md`，本文件不新增色碼、尺寸變數或 `src/web/ui` 元件。

## 1. 版面線框（≥ 1280px）

```
┌ 內容區（內距 --space-6）──────────────────────────────────────────────────┐
│ [ⓘ 正在檢視 王小明 的清單（唯讀）  回到我的清單]      檢視：(頭) 我自己 ▾ │
│ ┌ 指派給我的任務  5 ──── ☐ 顯示已完成 ┐  ┌ 自由待辦  3 ───────────────┐ │
│ │ ● 進行中  撰寫週報   ●預設 11/28 3時前 🔖│  │ [+ 新增待辦，按 Enter 建立 ] │ │
│ │ ● 待辦    校正儀器   ●預設 12/02 昨天 🔖│  │ ⠿ ☐ 訂購試劑       2 時前 ✕│ │
│ └──────────────────────────────────────┘  │ ⠿ ☐ 回覆審稿意見   昨天   ✕│ │
│ ┌ 我標記的任務  2 ─────────────────────┐  │     └ 週五前要寄出            │ │
│ │ ● 審查中  資料清理 (頭) ●預設 — 2天前 🔖│  │ ▸ 已完成 4        清除已完成 │ │
│ └──────────────────────────────────────┘  └─────────────────────────────┘ │
└───────────────────────────────────────────────────────────────────────────┘

```

- 三區皆為卡片：`--color-surface`、1px `--color-border`、`--radius-lg`。區塊標題列高 48、內距 0 16、下緣 border-subtle：標題 `--text-lg` 600 + 計數 Badge（neutral、`--radius-full`），右側為該區控制項。
- 頁首列：右側成員切換 `Select`（選項帶 Avatar，第一項固定「我自己」）；唯讀提示列只在檢視他人時出現。

## 2. 任務列（指派給我 / 我標記的，共用 TaskRow）

列高 `--row-height`、內距 0 16、以 `--color-border-subtle` 分隔。由左至右：
`StatusBadge`（唯讀）→ 標題（`--text-sm`，flex: 1，單行截斷）→ 負責人 Avatar `xs`（僅「我標記的」區顯示）→ 專案色點 + 名稱（text-secondary，寬 < 1280 時只留色點）→ 到期日（`--text-xs` tabular-nums，無則「—」）→ `<UpdatedAt>` → `PinButton`。

| 狀態 | 呈現 |
|---|---|
| 預設 | 如上 |
| hover | `--color-surface-hover` 底、游標 pointer |
| focus-visible | 標準 focus outline（內縮 2px） |
| 逾期未完成 | 到期日用 `--color-status-overdue-text` |
| 已完成（category=done） | 標題 text-tertiary + 刪除線 |

- 點擊列（PinButton 以外）→ `openTask(id)`。
- **指派給我**：預設只列未完成，依到期日近→遠（無日期排最後）；勾選「顯示已完成」後已完成接在最後。
- **我標記的**：依標記時間新→舊，含已完成；任務被刪除時該列自動消失。取消標記即樂觀移除該列，不需確認。

## 3. 自由待辦

### 3.1 新增列
區塊頂部 `Input` md 滿寬（外距 12 16），前置「+」圖示。Enter 建立 → 清空並保持 focus，新項目加在未完成清單**最上方**；空白無作用；Esc 清空失焦。送出中 / 失敗呈現比照 core QuickAdd §7.1。

### 3.2 待辦列（TodoRow）
```
 ⠿  ☐  訂購試劑                [進行中] 12/02  2 小時前  ✕
        └ 備註文字（--text-xs text-secondary，最多 2 行）
```
- 最小高 `--row-height`、內距 0 12；`⠿` 拖曳把手、`✕` 刪除為 iconOnly ghost sm，**僅 hover / focus-within 顯示**（把手 text-tertiary、游標 `grab`）。
- 標題是按鈕：點標題（或列上的空白處）、`Enter` → 開啟右側 inspector（§3.5）。**列上不再就地改標題 / 備註**，一律在 inspector 編輯。
- 狀態 chip（§3.4）：標題右側，一次點擊展開選單切換。到期日（`--text-xs`，有設才顯示；逾期未完成用 `--color-status-overdue-text`）。
- 勾選：Checkbox 立即切換（勾 = 完成、取消勾選回「待處理」）。
- 刪除：`✕` 立即刪除、不確認（輕量內容）；inspector 內的刪除需確認。

| 狀態 | 呈現 |
|---|---|
| 預設 / hover | 透明 / `--color-surface-hover`，顯示把手與動作鈕 |
| 編輯中 | 標題為 Input（accent 邊框 + focus ring） |
| 拖曳中（原位） | `opacity: .4`；插入位置顯示 2px accent 橫線 |
| 拖曳浮層 | surface 底、border、`--radius-md`、`--shadow-sm` |
| 已完成 | Checkbox 勾選、標題 text-tertiary + 刪除線、無把手 |
| 取消 | 標題 text-tertiary + 刪除線、無把手 |
| 延後 | 標題 text-secondary、無把手 |
| 已開啟 inspector | 列底 `--color-accent-soft` |
| 儲存失敗 | 還原內容，列下方 `--text-xs` danger-text「儲存失敗，請再試一次」 |

### 3.3 分組與「已完成」群組
「全部」檢視由上到下分三組（組內皆依 sortOrder）：
1. **主清單**：待處理 + 進行中，可拖曳 / 鍵盤排序（標題計數 = 此組數量）。
2. **延後與取消**：小標「延後與取消 N」（`--text-xs` text-tertiary）下列出延後、取消的項目，**沉到主清單後面**、不可排序、永遠展開。
3. **已完成**：清單底部收合列（高 32）：chevron +「已完成 N」text-secondary；**預設收合**，不可排序。右側「清除已完成」ghost sm → 確認 Dialog `sm`「刪除 N 筆已完成的待辦？」主要鈕 `danger`。N = 0 時整列不顯示。

**「清除已完成」只刪除狀態為「完成」的項目，延後與取消的項目保留**（Dialog 內文明說）。

### 3.4 小狀態與篩選
狀態共五種（後端欄位 `status`）：

| 值 | 標籤 | chip 色調（只用 Badge 語意色） |
|---|---|---|
| `todo` | 待處理 | 中性、透明底 + 邊框 |
| `doing` | 進行中 | accent（藍） |
| `deferred` | 延後 | warning（黃） |
| `cancelled` | 取消 | 中性（灰）；標題加刪除線 |
| `done` | 完成 | success（綠）；標題加刪除線 |

- **`done` 與 `isDone` 一致，由後端維護**：PATCH `status=done` → `isDone=true`；改為其他狀態 → `isDone=false`；只送 `isDone`：勾選 = `done`、取消勾選（原為 done 時）回 `todo`；同時送兩者以 `status` 為準。前端樂觀更新套用同一規則。
- chip 為 Menu 觸發鈕（`aria-label`「狀態：延後，點擊變更：<標題>」）；選單項目為五種狀態，目前狀態前顯示勾號。唯讀檢視時 chip 只是標籤。
- 卡片標題下方一排**篩選鈕**（`aria-pressed`）：全部 / 進行中 / 延後 / 取消 / 已完成，各帶數量。選「全部」為 §3.3 的分組檢視（可排序）；選單一狀態時顯示該狀態的平面清單（不可排序，無符合時顯示「沒有「延後」的待辦」）；「已完成」篩選直接展開已完成清單與「清除已完成」。篩選只存在前端，不寫入網址。
- 資料欄位：`status`（預設 `todo`）、`dueDate`（YYYY-MM-DD，可為 null）、`detail`（細節，長文，最長 50,000 字）；既有 `note` 沿用為「備註」（列上常駐顯示的短說明，最長 5,000 字）。migration `0007_personal_status`，既有 `is_done = 1` 的列回填 `status = 'done'`。

### 3.5 詳情 inspector（`?todo=<id>`）
點列開啟右側抽屜，外框、動畫、寬度（`--drawer-width`）與任務詳情抽屜（`.task-drawer`）完全一致；網址 `/me?todo=<id>`（檢視他人時為 `/me?user=<uid>&todo=<id>`），可分享、重整後保留，瀏覽器上一頁可關閉。

```
┌ 待辦詳情                                  ✕ ┐
│ 標題   [ 訂購試劑                         ] │
│ 狀態   [進行中 ▾]                           │
│ 到期日 [2026/12/02] ✕                       │
│ 備註                                        │
│ [ 一句話備註（會顯示在列表上）            ] │
│ 細節                           已儲存       │
│ [ 多行文字…                               ] │
├─────────────────────────────────────────────┤
│ 建立於 …  更新於 …              刪除待辦    │
└─────────────────────────────────────────────┘
```
- 標題、備註、細節：**失焦或 Ctrl+Enter（標題為 Enter）儲存**，欄位標題右側顯示「儲存中… / 已儲存 / 儲存失敗 · 重試」；標題不可為空（還原）。關閉或切換待辦時先送出未存內容。他人更新（輪詢）在未編輯且無未存內容時同步。
- 狀態：Select 一次選定即儲存；到期日：日期欄位變更即儲存，旁有「清除」鈕。
- 頁尾：建立 / 更新時間（`<UpdatedAt>`）與「刪除待辦」→ 確認 `alertdialog`「刪除待辦「…」？」（取消為預設焦點）。
- 關閉：✕、`Esc`（欄位內的 `Esc` 先結束編輯 / 儲存，再按一次關閉）、移除 `?todo`；關閉後焦點回到原本的列。找不到該待辦（已刪除）顯示「找不到這筆待辦」。
- 版面：≥ 1280px 頁面右側保留 `--drawer-width`，兩欄收為單欄且**自由待辦排到最前面**（被點的列不會被推出畫面）；< 1280px 為覆蓋式（沿用 shell 的遮罩）。
- **唯讀檢視他人清單**：inspector 可開啟，但標題、狀態、到期日、備註、細節皆為純文字，沒有輸入框與刪除。

## 4. PinButton（插槽升級）

- 簽名：`<PinButton taskId size?="sm" | "md" />`；`iconOnly` ghost Button，書籤圖示 16px，`sm` = 28、`md` = 32。
- 資料：全站共用一個「我的標記」查詢（同一 query key），所有 PinButton 讀同一份、樂觀更新；**永遠反映登入者自己的標記**（即使在檢視他人清單）。
- 點擊呼叫 `PUT` / `DELETE /api/personal/pins/:taskId`，並 `stopPropagation`，不觸發所在列 / 卡片的點擊或拖曳。

| 狀態 | 呈現 | 無障礙 |
|---|---|---|
| 未標記 | 線條書籤、`--color-text-tertiary` | `aria-pressed="false"`、label「加入我的標記」 |
| 未標記 hover | `--color-surface-hover` 底、`--color-text` | tooltip 同 label |
| 已標記 | 實心書籤、`--color-accent` | `aria-pressed="true"`、label「移出我的標記」 |
| 已標記 hover | `--color-accent-soft` 底、`--color-accent-hover` | tooltip 同 label |
| focus-visible | 標準 focus outline | — |
| 寫入中 | 顯示樂觀結果，暫不接受再次點擊 | `aria-busy` |
| 失敗 | 還原圖示；tooltip 改為「標記失敗，請再試一次」（danger，3 秒） | `aria-live="polite"` |
| 查詢載入中 / 未登入 | 不渲染（回傳 null，不佔位） | — |

- 引用處建議：List 列尾與 Kanban 卡片右上用 `sm`，未標記時可由引用處設為 hover 才顯示、已標記時常駐；TaskDrawer 標題列關閉鈕左側用 `md`、常駐。切換以 `--duration-fast` 過渡填色，不做彈跳動畫。

## 5. 唯讀檢視他人（`/me?user=<id>`）

- 頁首出現 info-soft 提示列（樣式同登入頁提示列）：「正在檢視 王小明 的清單（唯讀）」+ 文字連結「回到我的清單」。
- 區塊標題改為「指派給 王小明 的任務」「王小明 標記的任務」「王小明 的自由待辦」。
- 自由待辦：不渲染新增列、把手、`✕`、「清除已完成」；Checkbox 為 disabled 外觀但保留勾選狀態；狀態 chip 只是標籤；點標題仍可開啟**唯讀** inspector（§3.5）。篩選鈕照常可用。
- 任務列仍可點擊開啟 TaskDrawer；PinButton 照常運作（改的是我自己的標記）。
- 找不到該成員或已停用：EmptyState「找不到這位成員」+「回到我的清單」。

## 6. 空 / 載入 / 錯誤

| 區塊 | 空狀態（EmptyState，不放按鈕） | 載入 | 錯誤 |
|---|---|---|---|
| 指派給我 | 「目前沒有指派給你的任務」 | 3 列 Skeleton | 區塊內 ErrorState + 重試 |
| 我標記的 | 「還沒有標記的任務」，說明「在任務上點書籤圖示即可加入」 | 3 列 Skeleton | 同上 |
| 自由待辦 | 「寫下第一件待辦」，說明「只有你能修改這份清單」 | 新增列 + 3 列 Skeleton | 同上 |

三區各自獨立載入與報錯，互不阻擋；輪詢與 focus 重抓時靜默更新，不閃爍。唯讀檢視的空狀態文案把「你」換成成員名稱，且不顯示操作說明。

## 7. 鍵盤

| 按鍵 | 作用 |
|---|---|
| `C` | 聚焦自由待辦新增列（focus 在輸入框時不觸發；唯讀檢視無效） |
| `Tab` | 成員切換 → 指派給我 → 我標記的 → 自由待辦（篩選鈕 → 新增列 → 列）；列內順序：列本體 → PinButton（任務列）／把手 → Checkbox → 標題 → 狀態 chip → `✕`（待辦列） |
| `↑` `↓` | 在同一區的列之間移動 |
| `Enter` | 任務列：開啟 TaskDrawer；待辦標題：開啟 inspector；狀態 chip：展開選單（`↑` `↓` 選、`Enter` 確定） |
| `Space` | PinButton、Checkbox 切換；把手上為拿起 / 放下（dnd-kit 鍵盤感應器），拿起後 `↑` `↓` 移動、`Esc` 取消 |
| `Alt+↑` / `Alt+↓` | 待辦列直接上移 / 下移一格（不需拿起） |
| `Delete` | 刪除目前 focus 的待辦列（非編輯中），focus 移到下一列 |
| `Esc` | 取消拖曳；inspector 內結束編輯，再按一次關閉 inspector |
| `Ctrl+Enter` | inspector 的備註 / 細節：立即儲存 |

- 排序以 `aria-live="assertive"` 播報：「已拿起 訂購試劑，位置 2 / 5」「已移到位置 1」「已取消」。
- 刪除與取消標記後 focus 落在下一列；該區已空則落在新增列或區塊標題。

## 9. 給實作者的檢查清單

1. 三區皆有空 / 載入 / 錯誤三態，每列顯示 `<UpdatedAt>`。
2. 自由待辦可新增、勾選、拖曳排序（含鍵盤）、刪除、切換小狀態與篩選；重整後順序、狀態與完成狀態保留。
2a. inspector（`?todo=<id>`）可改標題 / 狀態 / 到期日 / 備註 / 細節並顯示儲存狀態，重整後仍在；刪除需確認；唯讀檢視時無輸入框。
3. PinButton 在 List、Kanban、TaskDrawer 引用處皆可切換，且不觸發外層點擊；標記後「我標記的」區不需重整即更新。
4. `/me?user=<id>` 完全唯讀，畫面上找不到任何可修改他人清單的控制項。
5. 1280px 與 768px 無水平捲軸；所有顏色皆取自 core token。

## 10. 匯報報告（產生「這段期間完成了什麼」）

個人頁標題列的「產生匯報報告」開啟對話框（`ReportDialog.tsx`）：選日期區間與內容 → 即時預覽 → 複製 / 下載 / 列印，方便向上級匯報。語氣見 [../product-principles.md](../product-principles.md)：這是讓人**整理自己做了什麼**的工具，不是績效評比；沒有項目時寫「這段期間沒有紀錄」。

**資料來源與口徑**（`GET /api/personal/report?from=&to=&user=&include=`，`server/app/personal_report.py`）

- 日界線以伺服器時區（`TZ`，預設 `Asia/Taipei`）計；區間**含頭尾日**（起始日 00:00 至結束日隔日 00:00），最長 366 天（超過 400）；日期格式須為 `YYYY-MM-DD`。
- **完成任務**：指派給該成員、`tasks.completed_at` 落在區間、目前仍為 done 類別狀態、未軟刪除（完成後又改回未完成的不算）。
- **完成待辦**：該成員自由待辦 `status = 'done'` 且 `personal_items.done_at` 落在區間。`done_at`（migration 0020）在狀態變為 done 時寫入現在時間、由 done 改回其他狀態時清為 NULL；既有資料回填為 `updated_at`；匯入舊匯出檔缺 `doneAt` 時同樣以 `updatedAt` 推得。
- **預估工時**：只加總有填 `estimate_hours` 的完成任務，回傳 `estimatedHours` 與 `hoursKnown`（件數）；沒人填就不回傳這兩個欄位，前端也不顯示「顯示預估工時」選項。
- 可選 `include=doing,deferred,cancelled,created`：`inProgress`（目前指派給他、進行中類別、建立於區間結束前的任務）、`deferredTodos`（延後 / 取消的待辦，**截至今日**的現況）、`createdTasks`（區間內他建立的任務）。預設只回完成事項。
- 權限同個人頁：登入即可；預設為本人，`user=` 指定他人為唯讀檢視（已停用或不存在的成員回 404，不洩漏）。
- 每種資料各一次批次查詢（專案名稱以 JOIN 取得），無 N+1。

**前端**

- 快速區間：本週 / 上週（週一至週日）、近兩週 / 近三週（含今天往前 14 / 21 天）、本月 / 上月、自訂（兩個原生日期欄）；預設本週；選項與區間記在 localStorage（`personal-report-prefs`），快速區間每次開啟依今天重算。
- 選項：已完成的任務、已完成的待辦（預設勾選）、進行中的任務、延後／取消的待辦、期間新建立的任務；依專案分組（預設開）、顯示預估工時（有填估時才出現）、顯示完成日期。
- 預覽每項前有勾選可排除；彙總句（例「11/17–11/23 完成任務 5 件、待辦 3 件」）依實際納入的項目重算。「可編輯文字」分頁可直接改文字，修改內容用於複製與 .md / .txt 下載（.csv 依預覽產生）。
- 輸出：複製（純文字條列 / Markdown / Markdown 表格 / 一行摘要）、下載 .md / .txt / .csv（CSV 含 UTF-8 BOM、CRLF，欄位依 RFC 4180 跳脫，`= + @` 開頭的文字加 `'` 前綴避免 Excel 當公式）、列印（`@media print` 只輸出報告內容）。
- 格式化是純函式（`reportFormat.ts`，含單元測試）；檢視他人（`?user=`）時為該成員產生，標題標示名稱。
